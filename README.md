# PDF to CMYK — Mac app (Fusion Nest)

Converts RGB PDFs to print-ready CMYK (U.S. Web Coated SWOP v2), with optional page resizing.

## Install

1. **[Download PDF-to-CMYK.dmg](https://github.com/fusionnest-ca/pdf-to-cmyk/releases/latest/download/PDF-to-CMYK.dmg)** (latest version).
2. Open the downloaded file and drag **PDF to CMYK** onto **Applications**.
3. Open it from Applications.

Requires an Apple Silicon Mac (M1 or later) running macOS 12 or newer.

## Updates

The app checks for updates once a day and offers new versions itself. You can also choose **PDF to CMYK → Check for Updates…**. All releases: [Releases](https://github.com/fusionnest-ca/pdf-to-cmyk/releases).
